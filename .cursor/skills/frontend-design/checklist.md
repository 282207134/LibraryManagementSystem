# Frontend Design Checklist

## 需求与目标

- [ ] 明确用户任务与核心操作路径
- [ ] 明确页面成功标准（效率、完成率、点击率等）
- [ ] 明确约束（技术栈、组件库、品牌规范、时间）

## 信息架构

- [ ] 首屏主任务清晰
- [ ] 内容层级不超过 3 层
- [ ] 主要信息在扫描路径上可被快速识别

## 视觉与布局

- [ ] 间距体系一致（不随意新增魔法数）
- [ ] 字号层级清晰，标题/正文/辅助信息区分明确
- [ ] 颜色语义统一（成功/警告/错误/中性）
- [ ] 组件圆角、边框、阴影风格一致

## 交互与状态

- [ ] loading/empty/error/disabled 已定义
- [ ] hover/focus/active 状态已定义
- [ ] 异步动作有反馈，可重复提交被防护
- [ ] 危险操作有确认或撤销策略

## 响应式与可访问性

- [ ] 320px 宽度下可用
- [ ] 关键组件在常见断点下不破版
- [ ] 键盘可达，focus 可见
- [ ] 对比度与文本可读性达标
- [ ] 错误提示不只依赖颜色

## 交付质量

- [ ] 变更说明包含设计理由与权衡
- [ ] 未破坏现有关键流程
- [ ] 样式与行为在主要页面回归通过
