# RLS 修复步骤说明（当前版）

本说明用于修复管理员查询失败、`/admin` 页面无法加载等问题。

## 步骤 1：重建 `is_admin()`

```sql
create or replace function is_admin()
returns boolean
language plpgsql
security definer
set search_path = public
as $$
begin
  return exists (
    select 1
    from users
    where id = auth.uid() and role = 'admin'
  );
end;
$$;
```

## 步骤 2：重建管理员读取策略

```sql
drop policy if exists "Admins can read all users" on users;
create policy "Admins can read all users" on users
  for select using (is_admin());

drop policy if exists "Admins can view all borrowing records" on borrowing_records;
create policy "Admins can view all borrowing records" on borrowing_records
  for select using (is_admin());
```

## 步骤 3：验证

```sql
select is_admin();
```

返回 `true` 或 `false` 即函数可用（不报错是关键）。

## 步骤 4：账号校验

```sql
select id, email, role from users where id = auth.uid();
```

如果 `role` 不是 `admin`，请更新后重登。

## 步骤 5：前端复验

1. 退出登录并重新登录  
2. 刷新 `/admin/dashboard`  
3. 若仍失败，检查前端 `.env` 是否指向正确 Supabase 项目
